# FinSight - Financial Web Application

FinSight is a full-stack financial web application built using React (with Vite) on the frontend and Node.js, Express, and MongoDB on the backend. It provides users with a seamless experience to sign up, log in, and use finance-related tools like an EMI Calculator and other insights.

## Features

- Modern frontend with React and Vite
- TailwindCSS for clean and responsive UI
- User authentication system (signup, login, session-based auth)
- Secure password hashing with bcrypt
- Input validation with express-validator
- MongoDB database with Mongoose ORM
- Session management using express-session
- Modular and scalable folder structure
## Tech Stack

### Frontend
- React
- React Router DOM
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB with Mongoose
- express-session
- bcrypt
- express-validator
- cors

## Installation and Setup

### Prerequisites
- Node.js and npm installed
- MongoDB installed and running locally (or use MongoDB Atlas)
